MidMan AI

A coding and game-development language model built from scratch in Rust: its own tensors, its own autograd, its own training loop. No pretrained weights and no ML framework.

Lab

Run the real model in your browser, compiled to WebAssembly. Train it, and watch the loss, the gradients and the attention.

Benchmarks

Where it stands

Working and tested: the tensor library with reverse-mode autodiff, the transformer layers (grouped-query attention, rotary embeddings, SwiGLU), the model, AdamW, an end-to-end training loop that memorizes a task, saving and loading model weights as standard safetensors files, a byte-level BPE tokenizer with its trainer, and the data path from text to batches: a license policy, a source manifest, secret scrubbing, exact deduplication, packing into token shards and a resumable batcher. Not started yet: fetching sources, mixing them by weight, saving optimizer state and training progress, and everything after them.

Built by MidMan Studio. The lab runs the same Rust code as the tests; nothing is reimplemented in JavaScript.
